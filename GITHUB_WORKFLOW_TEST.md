# GitHub workflow test

This harmless file was created to demonstrate Peter's first complete GitHub workflow.

The change follows this sequence:

1. Issue #3 records the task.
2. The `agent/github-workflow-test` branch isolates the work from `main`.
3. This commit saves the proposed file on that branch.
4. A draft pull request allows the change to be reviewed before merging.

Until the pull request is merged, the `main` version of the project remains unchanged.
